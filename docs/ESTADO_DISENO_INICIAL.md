# MovieInsight — estructura inicial del examen final

Este repositorio corresponde al examen final de Laboratorio de Programación 1 (IES Siglo 21).

## Diseño previsto
- Solución para Visual Studio 2017 y .NET Framework 4.7.2.
- Formulario principal maximizado con menú Sistema, Géneros y Visualizaciones.
- Diez formularios secundarios centrados.
- Clase DatosGlobales con RegistroGenero, Generos[10], IND, Meses[12] y Visualizaciones[10,12].
- Estética azul marino y dorado con recursos cinematográficos.
- Lógica de carga, consultas y estadísticas: siguiente etapa.

## Alcance del primer paquete
La primera versión de la solución y los formularios se está distribuyendo como archivo ZIP independiente para importar y comprobar en Visual Studio. Este documento no implica que todo ese ZIP ya esté sincronizado con GitHub.

## Abrir
Descomprimir la solución en una carpeta, abrir MovieInsight.sln, comprobar que esté instalado el paquete de desarrollo .NET Framework 4.7.2 y ejecutar con F5.
